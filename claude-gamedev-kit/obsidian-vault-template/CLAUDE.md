# My Obsidian vault
Plain markdown notes. Run `claude` from this folder to work on notes directly. Load the `obsidian-vault` skill for syntax rules.

## Layout
- `Games/<GameName>/`: one folder per game (Overview, Features/, Content/, Decisions.md, Devlog/)
- `Inbox/`: unsorted captures; file them when asked
- `References/`: tutorials, talks, articles I've saved
- `Templates/`: note templates (don't edit unless asked)

## Rules
- Keep frontmatter and `[[wikilinks]]` intact; update links when renaming.
- Edit surgically. Never rewrite a whole note. Log changes under `## Log` with dates.
- Never touch `.obsidian/` or attachments.
- When I say "note this" or "remember this for <game>", append to the right note; create one from `Templates/` if none exists.
